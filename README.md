# Apnashop-E-Commerce
Full Stack E-commerce web application built during a 4-week industrial training with Euphoria GenX (Kolkata) at Arka Jain University. Features a dynamic product catalog, user authentication, interactive shopping cart, and secure checkout workflows.

✨ Key Features
Dynamic Product Catalog & Navigation: Multi-category browsing (Mobiles, Laptops, Fashion, Electronics, etc.) with detailed product views, thumbnail switches, and stock status indicators.

User Authentication & Role Management: Secure sign-in and registration modals supporting distinct user roles (Buyers & Suppliers).

Smart Shopping Cart & Checkout Flow: Real-time cart management, dynamic pricing calculations, quantity controls, and secure multi-step shipping checkouts.

Modern UI/UX: Interactive promotional banners, trending product grids, and live shopping showcases built with clean styling and responsive layouts.

🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript, Responsive UI Frameworks

Backend & Logic: Server-side integration, data handling, and backend problem-solving modules

Version Control: Git & GitHub

🔮 Future Enhancements
Integration of secure third-party payment gateways (Razorpay/Stripe).

Migration to a cloud-based microservices architecture.

AI-powered product recommendation engine.
